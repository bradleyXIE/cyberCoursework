Packet Tracer behaviours found and designed around
  3650 physical-port configuration is only applied when it follows the rest
  of the running-config, so the generator emits those ports last.
  IOS DHCP on the 3650 honours one excluded-address range per subnet; the
  split scope on the cores overlapped, so DHCP moved to INTRANET and MAIL
  with ip helper-address on both cores (non-overlapping .11-.130 / .131-.250).
  The 2911 image has no IP SLA or object tracking and ignored OSPF default
  metrics; only EDGE-1 originates the default and each core has a floating
  static default (AD 250) to EDGE-2.
  Open the file and Fast Forward about 2-3 minutes of simulated time before
  testing so that STP, HSRP and OSPF converge.
