# CST4562 coursework

MSS Ltd network implementation and vulnerability assessment.

- [Combined group report](CST4562%20Group%20Coursework.docx) covers implementation, vulnerability analysis and the group activity appendix.
- [Implementation topology](CW_CST4562-Implementation.pkt) adds shared services, backup isolation, the simulated Internet endpoint and a secondary trunk. Open it in Packet Tracer 9.0.1. Use Logical view and zoom out to see the three department groups. Wait for DHCP and spanning tree to converge before testing.
- [Optimized baseline](CW_CST4562-Optimized.pkt) preserves the original network in a grouped logical layout. [Original topology](CW_CST4562.pkt) and the earlier topology reference remain available for comparison.
- [Implementation lab](implementation-lab/README.md) contains the PostgreSQL access and recovery check. [Simulator evidence](implementation-lab/evidence/PT-implementation-verification.txt) records the Packet Tracer observations.
- [Vulnerability lab](vulnerability-lab/README.md) contains the Docker runner and evidence used in Part II. The [standalone vulnerability report](CST4562%20Vulnerability%20Analysis.docx) is the earlier Part II deliverable.
- [Coursework brief](CST4562_CW.pdf) lists the assessment requirements.
